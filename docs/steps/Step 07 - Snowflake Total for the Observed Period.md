# Step 7 - Snowflake Total for the Observed Period

**Applies to:** All projects

## Purpose

Add every project total. This is the figure the Google Slot Calculator app reports for the same CSV and price per credit.

## Formula

```
Snowflake Total = SUM of all project totals
Cost            = Snowflake Total x Price per Credit
```

## Example

Sample Retail Co, 7 observed months (March-September 2026), $4.00 per credit.

124,151.27 + 105,091.22 + 52,042.34 + 29,963.27 + 16,002.23 + 6,971.35 + 2,890.10 = **337,111.77 credits = $1,348,447.08** (7 months)

## Notes

Nothing is averaged across projects, and slot ms and active time are never pooled across projects.
