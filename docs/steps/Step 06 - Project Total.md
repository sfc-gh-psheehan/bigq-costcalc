# Step 6 - Project Total

**Applies to:** Per project

## Purpose

Add up one project's months.

## Formula

```
Project Total = SUM of that project's monthly credits
```

## Example

Worked example: Sample Retail Co, project **analytics-prod**, March 2026 (the largest project-month in the sample).

16,849.79 + 18,209.62 + 19,623.62 + 16,147.33 + 18,044.61 + 18,908.71 + 16,367.59 = **124,151.27 credits**

## Notes

The report lists every project-month and each project's total.
