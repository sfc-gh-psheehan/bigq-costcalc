# Step 9 - Month-One Storage

**Applies to:** Projection

## Purpose

Set the starting storage volume, including time travel and failsafe.

## Formula

```
Month 1 TB = Initial Storage TB x (1 + Time Travel / Failsafe %)
```

## Example

Sample Retail Co, 7 observed months (March-September 2026), $4.00 per credit.

50 TB x (1 + 8%) = **54.0 TB**

## Notes

Initial storage is a customer input (required). Time travel / failsafe defaults to 0%; the sample uses 8%.
