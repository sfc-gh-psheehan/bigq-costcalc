# Step 2 - Calculate Average Slots

**Applies to:** Per project-month

## Purpose

Express the month's slot usage as an average number of slots over a standard 730-hour month.

## Formula

```
Average Slots = Slot Hours / 730
```

## Example

Worked example: Sample Retail Co, project **analytics-prod**, March 2026 (the largest project-month in the sample).

392,047.0 / 730 = **537.05 slots**

## Notes

730 hours per month is fixed. The app writes the same step as slot ms / 2,628,000,000.
