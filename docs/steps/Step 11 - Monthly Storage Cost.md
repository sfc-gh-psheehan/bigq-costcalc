# Step 11 - Monthly Storage Cost

**Applies to:** Projection

## Purpose

Price each month's storage.

## Formula

```
Storage Cost = Month N TB x Price per TB
```

## Example

Sample Retail Co, 7 observed months (March-September 2026), $4.00 per credit.

54.0 TB x $23.00 = **$1,242.00** (month 1); month 36 = $1,646.40

## Notes

Default price per TB per month is $23.00.
